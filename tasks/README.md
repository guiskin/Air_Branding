# Tarefas

- `backlog.md`: ideias e pendências, sem compromisso.
- `NNN-resumo.md`: tarefa aprovada, em andamento (modelo em `_modelo.md`).
- `concluidas/`: tarefas fechadas.

Ciclo: ideia no backlog, depois skill `planejar-tarefa` gera o arquivo, o usuário aprova, implementa-se em branch própria, `fechar-entrega` valida e commita, o arquivo vai para `concluidas/`. Correção pequena e óbvia não precisa de arquivo.

Não registre segredos nem dados reais de clientes aqui.
